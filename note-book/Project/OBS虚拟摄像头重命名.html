OBS虚拟摄像头重命名

OBS虚拟摄像头重命名
Windows 桌面工具，用于修改 OBS 虚拟摄像头在会议、录课、直播、多开等场景中的显示名称。

产品介绍

OBS虚拟摄像头重命名 是一个免安装的 Windows 可执行程序，下载后直接运行即可使用。

它适合这些场景：

  • OBS 虚拟摄像头在会议软件里显示为 OBS Virtual Camera，想改成更像真实摄像头的名字
  • 多开、直播、录课、远程会议时，需要调整虚拟摄像头显示名称
  • 想把虚拟摄像头名称改成 Logitech BRIO、USB Video Device、Integrated Camera 等常见摄像头名称

建议先校验 SHA256；如果校验一致，可以把程序加入信任列表后再运行。

使用前准备

  1. 系统必须是 Windows。
  2. 电脑已安装 OBS，并启用过 OBS 虚拟摄像头。
  3. 程序需要管理员权限，否则只能扫描，不能写入修改。
  4. WebView2 Runtime 需要可用；Windows 10/11 通常已内置。

使用方法

1. 启动 OBS 虚拟摄像头

先打开 OBS，点击「启动虚拟摄像头」。如果系统从未注册过 OBS 虚拟摄像头，工具可能扫描不到对应设备。

2. 管理员运行工具

右键 obs-vcamera-rename-v1.0.0.exe 或 GitHub 下载的 OBS.exe，选择「以管理员身份运行」。

权限提示

如果右上角显示 权限：非管理员，说明当前权限不够，需要关闭程序后重新以管理员身份启动。

3. 选择摄像头

在「选择摄像头」中选择 OBS Virtual Camera 或其他虚拟摄像头。

4. 填写新名称

可以直接输入英文设备名称，也可以选择预设名称。

常用预设示例：

  • Logitech BRIO
  • Microsoft LifeCam Studio
  • USB Video Device
  • Integrated Camera
  • Elgato Facecam

名称建议

新名称请使用英文名称。程序会拒绝明显的虚拟摄像头名称，避免改完之后仍然暴露虚拟摄像头特征。

5. 开通付费套餐

点击「应用重命名」时，如果设备未授权，程序会提示开通付费套餐。

点击「立即开通」后会打开授权支付页面。支付完成后，程序会在后台轮询授权状态；授权成功后即可继续应用重命名。

默认授权服务地址：

https://auth.certauth.cn

6. 应用重命名

授权通过并具备管理员权限后，点击「应用重命名」。

修改成功后，完全关闭 OBS、会议软件、浏览器，然后重新打开。部分软件会缓存摄像头列表，如果仍显示旧名称，可以重启电脑。

付费授权说明

授权信息

该工具接入了 py-auth 授权系统：

  • 软件名称：OBS虚拟摄像头重命名
  • 版本：1.0.0
  • 授权缓存有效期：7 天
  • 在线心跳超时较短，避免启动时长时间卡住
  • 付费页面由授权服务生成，支付完成后设备授权自动生效

如果已经支付但仍提示未授权，可以先点击「刷新」，或等待 10 到 30 秒后再次点击「应用重命名」。

常见问题

扫描不到 OBS Virtual Camera

先确认 OBS 已安装并启动过虚拟摄像头。必要时重启 OBS 或电脑后再打开工具。

提示需要管理员权限

修改系统设备名称需要管理员权限。请右键程序，选择「以管理员身份运行」。

修改成功后会议软件仍显示旧名称

会议软件通常会缓存摄像头列表。请完全退出会议软件和 OBS 后重新打开，仍不生效再重启电脑。

新名称不能使用中文

当前程序要求使用英文设备名称。这样兼容性更好，也更符合多数摄像头驱动的命名方式。

点击应用后提示请先开通付费套餐

说明当前设备 ID 尚未授权。点击「立即开通」完成支付，支付完成后等待程序自动刷新授权。

支付完成后还是不能应用

可以按顺序排查：

  1. 确认支付页面显示订单成功。
  2. 回到程序等待 10 到 30 秒。
  3. 点击「刷新」后再试。
  4. 关闭程序后重新以管理员身份运行。
  5. 检查本机网络是否能访问 https://auth.certauth.cn。

调试

按 Ctrl + Shift + D 可以打开调试界面，查看运行日志。

如果某个摄像头显示在列表里但不能修改，可以在调试界面查看对应错误信息。

  • WebView2 Runtime
开发模式
build.bat
编译 exe
build.bat build
安装 Wails CLI
build.bat install-wails

Linux/macOS 下只适合做代码开发和前端调试，实际功能只能在 Windows 上运行。

注意事项

  • 修改前建议先记录原始名称，方便后续恢复。
  • 不建议把真实摄像头也改成同名，避免会议软件里出现多个同名设备。
  • 修改系统设备显示名称存在风险，请只修改确认无误的虚拟摄像头。
  • 更新 OBS 或重装虚拟摄像头组件后，名称可能被恢复，需要重新修改。
